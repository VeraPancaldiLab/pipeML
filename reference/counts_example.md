# counts_example

Gene expression matrix from the Gide et al. (2019) metastatic melanoma
cohort. Rows correspond to genes (HUGO gene symbols) and columns to
patient samples. This dataset is used to compute features for training
machine learning models.

## Usage

``` r
counts_example
```

## Format

A numeric matrix with genes as rows and samples as columns.

## Source

Gide T.N., Quek C., Menzies A.M., Tasker A.T., Shang P., Holst J.,
Madore J., Lim S.Y., Velickovic R., Wongchenko M., et al. Distinct
Immune Cell Populations Define Response to Anti-PD-1 Monotherapy and
Anti-PD-1/Anti-CTLA-4 Combined Therapy. Cancer Cell. 2019;35:238–255.
doi: 10.1016/j.ccell.2019.01.003.
